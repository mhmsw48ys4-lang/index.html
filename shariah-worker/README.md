# فاحص شرعي مستقل

هذا المشروع مستقل عن Netlify القديم. يستخدم Cloudflare Worker كواجهة ومخدم API واحد، ويجلب بيانات SEC من الخادم لأن SEC يوضح أن data.sec.gov لا يدعم CORS في المتصفح. citeturn0search7

التشغيل:
1. اربط مجلد المشروع بـ Cloudflare Workers.
2. استخدم `wrangler.toml`.
3. شغّل Worker.
4. الموقع والـ API يعملان من نفس النطاق.

المنطق لا يعتبر "Financing income" كله فائدة، ولا يحول الإفصاح المفقود إلى صفر.
